## Annotation-guided ROI and coordinate contract

Resolve annotation `(block UUID, start, end)` mappings, deduplicating exact triples. Require valid offsets, exact monotonic OCR-word alignment and selected mapped text equal to the unchanged reference after casefolding and whitespace normalization. Reject meaningful internal-word boundary cuts: omitted alphanumeric characters and hyphen variants are unsafe; punctuation-only boundary fragments are allowed. Resolve all selected words, not a target-text search hit. Unresolved/ambiguous mappings are ineligible. No OCR/reference search fallback, inferred replacement region, changed answer, prior model correctness or confidence may determine eligibility.

These rules intentionally use reference-associated annotations and reference text to select the population and region. **The localizer and resulting cohort are label privileged even though target text never enters prompts.** This is a positive control for evidence availability, not a fair deployable selector or a mathematical performance upper bound.

Require one PDF page, rotation0 and UserUnit1. OCR boxes are in the top-left CropBox frame; source renders use the MediaBox. Require CropBox contained within MediaBox. Map coordinates with the recorded scale and offset between these frames, including nonzero origins and the vertical origin change. Require valid in-page word boxes and OCR/CropBox aspect agreement within at most one OCR-raster-pixel rounding error on each axis: `abs(ocr_width*crop_height - ocr_height*crop_width) <= crop_width + crop_height`. Three contained differing-box cases and one equal-box case were checked visually before preparation; two noncontained CropBox regimes are excluded, with no guessed intersection transform. Other rotations, UserUnits and unreconciled aspect ratios fail closed.

Union all selected word boxes. Map outward using floor left/top and ceil right/bottom. Context margin on each side is twice the median selected-word height after mapping. Take ceil expanded dimensions, at least256×256 source pixels, center on the union with floor left/top, and shift inside source boundaries; cap at source dimensions and require all selected evidence remains covered. No blank padding or source upsampling. Reject expanded area above25% of page area or an infeasible window. Preserve exact boxes, selected-word provenance, transform, padding and exclusions in the audit.

The 256-pixel minimum window prevents the local processor's65,536-minimum-pixel rule from silently enlarging native inputs. The actual processor grid must equal the intended grid. This window adds real context and does not certify that the remaining context is sufficient. The recorded preparation implementation and source audit, not an assumed thumbnail coordinate system, define the realized geometry.

## Ten independent calls per report

At each overview ceiling256,512,1,024 run `direct_b`, `native_b` and `degraded_b`. Add one standalone `highres` full-page call with ceiling4,096. Regional views have ceiling1,024. Ceilings are not guaranteed token counts. Use the unchanged no-upsample 32-pixel-grid sizing routine and frozen source renders. Native means the fixed-DPI PDF render, not intrinsic photographic pixels.

Frozen Qwen3-VL-4B-Instruct revision `ebb281ec70b05090aa6165b016eac8ec08e71b17`, BF16, SDPA, greedy generation,64 new tokens and `ANSWER:` assistant prefill. System: `You answer questions accurately based on the provided images.` Common instruction: `Answer by copying the relevant single text span from the page, including any units. Do not explain.`

Direct/highres: one image and original question followed by newline and the common instruction. Native/degraded: one fresh user message with overview first, regional image second, and text `The first image is the full page. The second image is an enlarged region of the first image.` followed by newline, original question, newline and the common instruction. There is no previous answer, intermediate assistant history, OCR, annotation label, region direction, reference answer or reference transcript in a request. The generation prefill is retained.

For each report, native ROI pixels and output dimensions remain identical across all three budgets. Degraded pixels come solely from the corresponding actual overview: project the same integer source ROI into floating-point overview coordinates, then BICUBIC-resize that box to the native output size. No independent integer rounding or reading original ROI pixels for degraded construction. Within each budget, native/degraded share overview pixels, prompt, dimensions, processor grids and input-token counts. Both image blocks must reach the processor. Save messages, source/ROI and ordered pixel hashes; validate actual grids and paired invariants. Two-stage filtering is part of the intervention, not a pure frequency decomposition.

## Outcomes and paired analysis

Use the unchanged full-response ANSWER parser. Invalid/empty predictions score zero; truncated generations remain in denominators and are flagged. Primary official EM uses the pinned author evaluator's one-span, empty gold/predicted scale path, not a claim to implement every TAT-DQA task. Secondary: conservative text EM, official F1 and diagnostic ANLS. ANLS is not an official TAT-DQA metric. The upstream evaluator can normalize punctuation, articles and numeric forms; an official match is not independent proof of correct units/sign/content. Keep raw responses and all metric disagreements visible.

Define `D_b(i)=official_EM(native_b,i)-official_EM(degraded_b,i)`. The **sole primary contrast is mean(D_256)** (`native_256_minus_degraded_256`). Secondary: `mean(D_256-D_1024)` (`detail_256_minus_detail_1024`), D512 and D1024, native/degraded versus matching direct at each budget, and comparisons with highres. Report all ten action means, official fixes/harms relative to matched direct with appropriate conditional denominators, both directions of native/degraded discordance, answer agreement and format/truncation counts.

Use10,000 paired bootstrap resamples of the85 original source reports, seed20260926. Carry all ten actions together and form interactions within report before resampling. Report95% percentile intervals as exploratory/unadjusted. No action-level pseudo-replication, post-hoc complete subset, outcome-driven sample extension or redundant prior94 sensitivity. Narrow or collapsed empirical intervals can reflect few discordances and do not establish population equivalence or absence of rare effects. Related company/templates may still correlate.

A positive resolution interaction can arise solely because degraded256 becomes worse. Show absolute native quality and native−direct before claiming practical usefulness. Native−direct alone also changes focus, token count and re-encoding. Native−degraded provides the matched fidelity comparison, conditional on privileged ROI geometry. A best-over-budgets/ROIs result is not the primary result or a deployed policy. No learned controller, transfer, novelty, causal attention or internal image-neglect claim follows from this panel.

## Condition-blinded content audit and descriptive advancement

After completion, audit **all native256/degraded256 parsed-answer changes**, including pairs where official EM says both correct or both wrong. Also include differing raw responses when either parse is invalid. Use the exact parsed strings for this selection, without another normalization that could hide units or signs. Keep the main quantitative scores unchanged.

Randomize native/degraded identities to A/B using a fixed per-example seed20260926. The reviewer sees the original full source page, question, unchanged reference and both complete raw responses, without condition names, scores or the A/B key. Record judgments before revealing the key. Categories: content difference, formatting-only difference, both substantively valid, both substantively wrong, ambiguous/uncertain; for content differences record which answer is unambiguously supported. Explicitly check units, signs, quantities and reference ambiguity. Preserve all reviewed IDs, selection denominators, judgments and later revealed mappings. The condition-blinded, outcome-selected judgments are descriptive; they do not constitute independent expert validation or an additional formal test.

Quantitative advancement requires primary mean>=2pp, its paired95% CI lower>0, and native256 official EM>=direct256 official EM. This threshold is not a power guarantee. A subsequent **descriptive semantic gate** additionally requires at least3 distinct reports with unambiguous native-only content repairs and positive net content repairs (native-only repairs minus reverse content harms) across the full selected audit. Ambiguous and formatting-only cases do not count as content repairs. Report both stages even when either fails; automatic controller training is always false.

Passing only motivates validation on new original reports with a nonprivileged selector and a separately planned evaluation. A failed or uncertain gate is a bounded result, not proof that VLMs cannot use detail. Check highres quality/cost before selecting future scope; reference-guided localization may have no deployable advantage.
