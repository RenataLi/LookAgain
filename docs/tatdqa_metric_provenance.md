# Secondary TAT-DQA metric: provenance and scope

The standalone `experiments/tatdqa_metrics.py` exposes
`score_official(prediction: str, target: str) -> dict` with `official_em` and
`official_f1`. It implements the **single-string-span, empty-gold-scale,
empty-predicted-scale** path of the creator-endorsed evaluator. It is a narrow
adapter, not a reproduction of the full TAT-DQA benchmark or its other answer
types. The project's primary metric is defined separately.

## Port behavior

Relevant normalization, numeric-formatting, and token-F1 helper bodies are
copied unchanged. Unused date parsing, dataset aggregation, pandas, and SciPy
dependencies are omitted. NumPy is already a project dependency and is retained
for numeric checks and the upstream F1 rounding semantics.

The wrapper formats the prediction and target **independently**, each with empty
scale, then compares normalized strings and computes token-set F1. With one span
on each side the assignment problem is exactly one pair. There is no scale
parameter, target-derived prediction scale, or alternate-answer matching.
The caller must verify the source annotation has one span and empty gold scale
before invoking this adapter; that annotation information is unavailable from
the two string arguments alone.

Author behavior is preserved rather than corrected: literal empty predictions
score zero, while whitespace-only strings follow normal normalization; articles
and punctuation may disappear; numeric strings are formatted according to the
source helpers, including rounding; token multiplicity is ignored for F1;
token-F1 does not enforce matching numbers inside mixed text. For example,
`2019 revenue` versus `2018 revenue` has EM 0 and F1 0.5. These details make the
secondary metric inappropriate as a substitute for stricter primary grading.

## Parity validation

The retrieved source hashes were verified before execution. Original reviewed
function/class AST nodes were loaded into an isolated namespace and the original
`TATEmAndF1.__call__` / `get_overall_metric` path was exercised with a one-element
gold answer list, `answer_type="span"`, and both scales empty. Only SciPy's
assignment call was replaced: the temporary function **asserted a 1×1 matrix**
and returned row 0 / column 0, the unique feasible assignment. It does not claim
parity for larger matrices. No upstream function bodies were rewritten in this
reference execution. No extra packages were installed.

The adapter matched all **5,625 pairs from 75 distinct strings**, 48 explicit
edge-case fixtures, and an additional rounding boundary. Coverage includes
text, articles, punctuation, whitespace, empty strings, repeated/reordered
tokens, numbers, currency, percentages, scale words, parenthesized negatives,
years, and non-ASCII characters. A single-pair F1 of 0.025 rounds to 0.02 under
the author's NumPy semantics; Python's ordinary `round(float, 2)` would give
0.03, so that substitution is intentionally avoided.

The 48 expected output fixtures are stored directly in
`tests/test_tatdqa_metrics.py`, allowing regression tests without network access
or the upstream repository. Their expected values were obtained from the
independent reference path, not generated by this adapter. The tests also reject
non-string/multi-span arguments and verify that gold scale cannot be injected.

Run from the repository root:

```text
python -m pytest tests/test_tatdqa_metrics.py
```

These checks validate grading behavior on synthetic strings. They contain no
model runs, development-sample outcomes, or held-out benchmark data.
