# Positioning the evidence-availability diagnostic

Checked against primary arXiv records on 2026-09-26. This is a focused related-work update, not a systematic review or novelty certification.

**GapSight is particularly close to the original LookAgain controller proposal.** [Zhu et al., *Learning to Look Again: Loss-Gap Supervision for Free-form Crop Routing in Vision-Language Models*, arXiv:2608.21762v2](https://arxiv.org/abs/2608.21762v2), submitted August 22 and revised August 29, 2026, describes a lightweight router trained from the target model's answer-loss or option-margin changes under crop-augmented inputs. It predicts whether to inspect again, expected utility and a continuous region. Thus a generic claim to invent utility-supervised crop routing would be unsupported. This repository has not reproduced that method, and its reported benchmark numbers must not be treated as a local baseline.

[Avogaro et al., *SPARC: Separating Perception And Reasoning Circuits for Test-time Scaling of VLMs*, arXiv:2602.06566v3](https://arxiv.org/abs/2602.06566v3), revised June 24, 2026 and listed as accepted at ICML 2026, separates visual search from subsequent reasoning. It also discusses low-resolution global context with higher-resolution selected regions. Varying overview resolution and inspecting a relevant region therefore has clear precedent; it is a diagnostic intervention here, not itself a novel method.

The present contribution is narrower: a reproducible sequence of controlled measurements for one frozen model, including matched native/degraded input geometry, checks of conversation framing, source annotation geometry, official-versus-strict scoring and complete case review. These are useful research artifacts even if their result is negative. Stronger publication claims require a distinct question, an implemented comparison with the closest method, genuinely untouched reports, a second model family and a nonprivileged selector. One local document panel cannot establish transfer to natural-image visual reasoning.

In v5, annotation chooses where to look, so a positive result would establish available useful evidence conditional on that privileged location. A learned policy would still need to find the region without reference answers and decide whether its expected benefit justifies the full measured cost. A negative result would apply to this frozen task/request/model regime, not disprove active vision in general.
