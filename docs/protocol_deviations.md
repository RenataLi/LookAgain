# Pilot protocol deviations and completion checks

This log accompanies protocol v0.1. It preserves the distinction between the original intentions and the implemented experiment; the protocol is not silently rewritten after observations.

## Recorded before the completed 400-image analysis

- **Resolution selection.** No separate development accuracy/cost sweep was completed. The approximately 1,024-token overview budget was fixed as an engineering setting, with a paired approximately 4,096-token full-image control on every pilot example. Neither setting is claimed optimal. A later experiment needs a separate resolution-selection panel. The native images are mostly small, so this comparison often upsamples existing pixels.
- **Engineering sample size.** After initial four-image checks, a 16-image / 128-call response-format check replaced the suggested 64-example engineering pass. It established format and memory feasibility only. Failed and superseded runs are excluded from the main experiment; see `preflight_notes.md`.
- **Response format.** The assistant `ANSWER:` prefix is prefilled for short-answer branches and generated by the reasoning branch. This intervention was fixed before restarting the full panel and is disclosed in the run configuration. It prevents boilerplate formatting errors but does not restrict answer vocabulary or use reference answers.
- **Timing repeat subset.** At 16:32 UTC on 25 September 2026, while the main run was still in progress and before its aggregate analysis, the first eight manifest examples were selected for one separate repetition of all actions after the full run. Selection uses manifest order, not outcomes. This is a small timing-stability diagnostic; it cannot characterize all hardware or generation variability. The main accuracy estimates use only the original full run. Main-run alternative-action order is deterministically shuffled separately for each example.
- **Secondary summaries.** Crop-exclusive rescues, oracle comparisons, descriptive question-type/image-size slices, and conditional repair/corruption rates are generated separately from the frozen inference package. They preserve the recorded exact-match grades and include their own provenance. They are exploratory diagnostics, not additional confirmatory hypotheses.

## Scope retained

All 400 planned development examples and eight actions must complete before the primary report is treated as final. No main-run prompt, image budget, sample membership, or answer grading is changed in response to intermediate outcomes. No controller training or held-out transfer evaluation is included in this pilot. A controller decision must cite the completed evidence, including harms and cost, and distinguish feasible actions from privileged hindsight selection.
